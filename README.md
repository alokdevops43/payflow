✦ About

Payflow is an editorial-style payment infrastructure experience focused on typography, motion, interaction and product storytelling.

The website combines cinematic page transitions, scroll-driven animations, an exploded product experience, interactive payment UI and an experimental poster gallery into one cohesive visual system.

🎨 Design Direction

Payflow follows an editorial, minimal and cinematic visual language.

The design focuses on:

Strong typography
Large-scale compositions
Hairline rules
Generous whitespace
Flat color fields
Editorial photography
Controlled motion
Asymmetrical layouts
Precise micro-interactions

The visual system uses Bodoni Moda for its editorial character and Instrument Sans for functional interface elements.

🌓 Theme System
☀️ Light Mode

A warm editorial environment built around plaster, paper, blush and dark typography.

🌙 Dark Mode

A deeper visual system using near-black and navy surfaces with soft paper typography and restrained pink accents.

Both themes are individually designed rather than simply inverted.

◇ Experience

Editorial Interface
Typography, photography and product UI work together as one composition.

Motion System
Scroll choreography, exploded components, image reveals and cinematic page transitions create the visual rhythm.

Product Experience
Payment interfaces, developer documentation, pricing and transaction concepts make the website feel like a real product rather than a static landing page.

Interactive System
Navigation, theme switching, pricing calculations, API tabs, FAQ interactions and poster movement are implemented with Vanilla JavaScript.
